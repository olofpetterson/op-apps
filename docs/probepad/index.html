Everything You Need

Professional API testing tools, designed for mobile.

👁 PRO

Endpoint Monitoring

Mark a saved request as watched and ProbePad runs it in the background, then tells you when it starts failing. It shows when the last check happened — iOS decides when the next one is granted.

📱 Free + PRO

Home & Lock Screen Widgets

Last Request and Request Status on your Home Screen, plus a Lock Screen circular — all free. The Endpoint Monitor widget, showing a watched endpoint's last result, is PRO.

🔍 Free

Spotlight Search

Your request names and hosts are searchable straight from the Home Screen. Tap a result to open it. Secrets and environment values are never indexed, and you can switch indexing off.

⏹ Free

Cancel a Running Request

One tap stops an in-flight request and tears the connection down. The cancelled attempt still lands in your history.

🍪 Free

Find in Response & Cookie Replay

Search inside a response body with a live match count, copy a single header value, and send a returned Set-Cookie straight back as a request header.

📋 Free

cURL Import — Free

Paste a cURL command, get a request. Free for everyone, and staying free — bulk Postman and OpenAPI imports are the PRO ones.

📡

HTTP Requests

GET, POST, PUT, PATCH, DELETE with full header and body control. Multipart/form-data with file upload built in.

⚙

GraphQL

Dedicated query editor with variables, operation names, and pretty-printed responses. Run queries, mutations, and subscriptions.

🔌

WebSocket

Open WebSocket sessions, send text and binary frames, and inspect every message in a live transcript.

📁

Collections & Environments

Group requests into named, colour-coded collections. Switch between dev, staging, and production with one tap.

🔒

Secrets Vault

Store API keys securely in the iOS Keychain with Face ID / Touch ID protection. Secrets never leave your device.

📈

Response History & Diff

Compare responses with JSON diff. Track status, latency, and payload changes over time.

💬

Siri & Shortcuts

"Run Saved Request" and "Send HTTP Request" App Intents for Siri, the Shortcuts app, and Focus automations.

🔁

Import & Export

Import Postman v2.1 collections, paste cURL commands to create requests, and export back to cURL.

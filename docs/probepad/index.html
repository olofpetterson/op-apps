From cURL to response in three steps

1. Reuse your request

Paste a cURL command and get an editable request. Free.

2. Run it and read the response

Status, timing, headers and JSON — as a tree or as raw text.

3. Keep working

Save requests in collections, look at response history, and diff two responses. Free.

What PRO adds

  • Environments and variables
  • A secrets vault in the iOS Keychain
  • Postman and OpenAPI import
  • OAuth 2.0
  • GraphQL
  • WebSocket
  • Background endpoint checks

PRO is a one-time lifetime purchase, or yearly with a seven-day free trial. Prices for your region are shown in the app.

Private by design

Your requests, responses and secrets are stored on your device. No account, no analytics, no third-party SDKs. Requests go from your device straight to the API you are calling. ProbePad does not sync between devices.

Background checks

With PRO you can mark a request as watched. ProbePad runs it again in the background and notifies you if it fails. iOS decides when background checks run, so this is not real-time monitoring — ProbePad shows when each endpoint was last checked.

Home Screen and Lock Screen widgets show a saved request's last status. Free.
